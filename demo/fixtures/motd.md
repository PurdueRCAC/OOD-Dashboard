## Welcome to the Demo Cluster

This is a **demo** of the HPC Dashboard. Every number you see is invented —
there is no scheduler, no allocation database, and no real filesystem behind
these widgets.

Things worth clicking:

- **Cluster Status** — 82 nodes across five families, including L40 and H100
  GPU nodes, in mixed states.
- **My Jobs** — 250 jobs over the last 60 days. Try the date range picker, the
  column filters, and the CSV/XLSX export.
- **Announcements** — includes a live outage and an upcoming maintenance
  window, colour-coded by type.
- Click any job ID for the full `sacct`/`scontrol` detail, or any node name for
  the jobs running on it.

Deployment instructions are in the project README.
